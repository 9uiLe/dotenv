### 複雑テンプレート

参考: `scripts/cli/simulator-run.sh`, `scripts/cli/cleanup-claude-branches.sh`

```bash
#!/bin/bash
#
# @PURPOSE: {目的}
# @INPUT:
#   - {入力の説明}
# @OUTPUT:
#   - 終了コード 0: 成功
#   - 終了コード 非0: 失敗
# @USAGE: {使用場面}
# @CALLER: {呼び出し元}
# @EXAMPLE: {実行例}
#

set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "$0")" && pwd)"
source "$SCRIPT_DIR/lib/common.sh"
PROJECT_ROOT="$(resolve_project_root)"

# --- 設定 ---
# {環境変数のデフォルト値設定}

# --- 引数チェック ---
# {位置引数がある場合のバリデーション}

# --- クリーンアップ ---
cleanup() {
    # TODO: 一時ファイルの削除、ロックの解放など
    :
}
trap cleanup EXIT

#=============================================================================
# ヘルパー関数
#=============================================================================

# TODO: ヘルパー関数を定義

#=============================================================================
# メイン処理
#=============================================================================

main() {
    local start_time
    start_time=$(date +%s)

    print_header "{スクリプト表示名}"

    log_step "{ステップ1の説明}..."
    # TODO: ステップ1の処理

    log_step "{ステップ2の説明}..."
    # TODO: ステップ2の処理

    # --- 完了サマリー ---
    local duration=$(($(date +%s) - start_time))
    print_footer "処理が完了しました!（${duration} 秒）"
}

main "$@"
```

## プレースホルダーの置換

テンプレート内の `{...}` を収集した情報で置換する:

| プレースホルダー | 置換元 |
|----------------|--------|
| `{目的}` | ステップ 1 で収集した目的（1行） |
| `{入力の説明}` | ステップ 2 の質問 2 の回答 |
| `{使用場面}` | ステップ 1 の目的から導出 |
| `{呼び出し元}` | ステップ 2 の質問 3 の回答 |
| `{実行例}` | ファイル名と入力パラメータから生成 |
| `{スクリプト表示名}` | ファイル名をタイトルケースに変換 |
| `{処理名}` | 目的の短縮形 |

## ベストプラクティスの反映

ステップ 3 で取得したベストプラクティスを以下の方法でテンプレートに反映:

- エラーハンドリングの推奨パターン → テンプレートの該当箇所にコメントとして追記
- パフォーマンスの注意点 → TODO コメントの近くに注意事項として追記
- 移植性の考慮 → macOS 固有のコマンドを使用する場合に注意コメントを追記
