# Markdown ベストプラクティスガイド

## 概要

Markdown ファイル（`.md`）を作成・編集する際に参照するベストプラクティスガイドです。

Google Markdown Style Guide と GitHub Markdown Syntax の推奨事項を統合し、このプロジェクトで一貫した Markdown を書くための規約をまとめています。

## 対象読者

- Markdown ファイルを新規作成する場合
- 既存の Markdown ファイルを編集・改善する場合
- Markdown ファイルのレビューを行う場合

## ドキュメント一覧

| ファイル | 内容 |
|----------|------|
| [01-formatting.md](./01-formatting.md) | 基本的な書式ルール（見出し、テキストスタイル、空行、インデント） |
| [02-structure.md](./02-structure.md) | ドキュメント構造パターン（タイトル、セクション構成、ナビゲーション） |
| [03-elements.md](./03-elements.md) | 要素別ベストプラクティス（テーブル、リスト、コードブロック、リンク、画像） |
| [04-checklist.md](./04-checklist.md) | Markdown レビューチェックリスト |
