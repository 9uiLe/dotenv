## 1. 見出し

### ATX スタイルを使用する

見出しには `#` を使用する。下線スタイル（`===` / `---`）は使用しない。

```markdown
<!-- Good -->
# 見出し 1
## 見出し 2
### 見出し 3

<!-- Bad（下線スタイル） -->
見出し 1
========

見出し 2
--------
```

### 見出しの前後に空行を入れる

見出しの前後には必ず1行の空行を入れる。

```markdown
<!-- Good -->
前のセクションのテキスト。

## 新しいセクション

新しいセクションのテキスト。

<!-- Bad（空行なし） -->
前のセクションのテキスト。
## 新しいセクション
新しいセクションのテキスト。
```

### `#` の後にスペースを入れる

```markdown
<!-- Good -->
## 見出し

<!-- Bad -->
##見出し
```

### 見出しレベルは順番に使用する

レベルを飛ばさない。`## H2` の次は `### H3`。

```markdown
<!-- Good -->
## セクション
### サブセクション
#### 詳細

<!-- Bad（H2 の直下に H4） -->
## セクション
#### 詳細
```

## 2. テキストスタイル

### 強調の使い分け

| スタイル | 用途 | 構文 |
|----------|------|------|
| **太字** | 重要な用語、UI 要素名 | `**テキスト**` |
| *イタリック* | 補足、注意書き | `*テキスト*` |
| ~~打消し~~ | 非推奨、削除予定 | `~~テキスト~~` |
| `コード` | コード、コマンド、ファイルパス | `` `テキスト` `` |

### 強調のアスタリスク統一

太字・イタリックにはアスタリスク（`*`）を使用する。アンダースコア（`_`）は使用しない。

```markdown
<!-- Good -->
**太字** と *イタリック*

<!-- Bad -->
__太字__ と _イタリック_
```

## 3. 空行と改行

### セクション間に空行を入れる

見出し、段落、リスト、コードブロック、テーブルの前後には空行を入れる。

```markdown
<!-- Good -->
テキスト段落。

- リスト項目 1
- リスト項目 2

次の段落。

<!-- Bad -->
テキスト段落。
- リスト項目 1
- リスト項目 2
次の段落。
```

### 改行にはバックスラッシュを使用する

段落内で明示的に改行を入れたい場合は、行末にバックスラッシュ（`\`）を使用する。末尾の2スペースによる改行は使用しない。

```markdown
<!-- Good（バックスラッシュ） -->
1行目のテキスト\
2行目のテキスト

<!-- Bad（末尾の2スペース） -->
1行目のテキスト
2行目のテキスト
```

> [!NOTE]
> 末尾の2スペースは目視で確認しづらく、エディタの「末尾空白除去」機能で意図せず削除される場合がある。バックスラッシュは意図が明確で安全。

### 末尾の空白を残さない

行末に不要なスペースやタブを残さない。

### ファイル末尾に改行を入れる

ファイルの最終行の後に1つの改行（空行）を入れる。

## 4. 文字数制限

### 1行80文字を目安にする

ソースの可読性と差分レビューのしやすさのため、1行80文字を目安に改行する。

ただし、以下は例外として80文字を超えてよい:

- URL を含むリンク
- テーブル
- 見出し
- コードブロック内のコード

```markdown
<!-- Good（80文字で折り返し） -->
Markdown ファイルは1行80文字を目安に記述する。
長い文章は適切な位置で改行し、
ソースファイルとしての可読性を保つ。

<!-- Good（リンクは例外として1行に記述） -->
詳細は [Google Markdown Style Guide](https://google.github.io/styleguide/docguide/style.html) を参照。
```

> [!TIP]
> この制限はレンダリング結果ではなくソースファイルの可読性を目的としている。コードレビュー時の横スクロールを減らす効果がある。

## 5. インデント

### リストのネストは4スペース

ネストしたリストには4スペースのインデントを使用する。

```markdown
<!-- Good（4スペース） -->
1. 項目 1
    - サブ項目 A
    - サブ項目 B
1. 項目 2

<!-- Bad（2スペース） -->
1. 項目 1
  - サブ項目 A
  - サブ項目 B
1. 項目 2
```

### コードブロック内のインデントは内容に従う

コードブロック内のインデントは、そのコードの言語規約に従う（Swift なら4スペース、YAML なら2スペース等）。
