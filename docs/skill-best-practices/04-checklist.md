## 新規スキル作成チェックリスト

### フロントマター

- [ ] `name` がディレクトリ名と一致している
- [ ] `name` が小文字・数字・ハイフンのみで構成されている
- [ ] `description` が三人称で書かれている
- [ ] `description` にトリガーワードが含まれている
- [ ] `allowed-tools` に必要なツールが全て含まれている
- [ ] `allowed-tools` に不要なツールが含まれていない
- [ ] Task() で呼び出す Agent が `.claude/agents/` に存在する
- [ ] Skill() で呼び出す Skill が `.claude/skills/` に存在する
- [ ] フィールド順序が `name` → `description` → `argument-hint` → `allowed-tools` である

### SKILL.md 本体

- [ ] 500行以下である
- [ ] 「概要」セクションがある
- [ ] 「使用方法」セクションがある（基本使用 + 引数付き）
- [ ] 「実行フロー」セクションがあり、ステップ番号が付いている
- [ ] 「参照」セクションがあり、関連ファイルが列挙されている
- [ ] Claude が既に知っている一般的知識を冗長に説明していない
- [ ] プロジェクト固有の情報に集中している

### 対話的情報収集（AskUserQuestion 使用時）

- [ ] 質問に `question`, `header`, `multiSelect`, `options` が全て指定されている
- [ ] 選択肢が4つ程度（多すぎない）
- [ ] 各選択肢が `**タイトル**: 説明文` の形式

### 検証ステップ

- [ ] 品質検証のステップが含まれている
- [ ] 検証失敗時の対応（自動修正 or ユーザー確認）が記載されている

### ディレクトリ構成

- [ ] 300行以下ならシンプル型（SKILL.md のみ）
- [ ] 300-500行なら複合型への分離を検討済み
- [ ] 500行超なら複合型に分離済み
- [ ] 参照は1レベル深いまで（reference.md, examples.md）

### CLAUDE.md との整合性

- [ ] Available Skills テーブルに新しいスキルが追加されている
- [ ] 説明文が SKILL.md の description と整合している

## 既存スキル改善チェックリスト

### 構造の改善

- [ ] 500行を超えていないか → 超えている場合は複合型に分離
- [ ] 不要な一般的知識の説明を削除できないか
- [ ] AskUserQuestion のパターンがプロジェクト規約に沿っているか

### 検証の改善

- [ ] 検証ステップが含まれているか → ない場合は追加を検討
- [ ] エラー対応セクションが十分か

### 整合性の改善

- [ ] CLAUDE.md の説明文が最新か
- [ ] 参照セクションのリンクが全て有効か
- [ ] allowed-tools に過不足がないか
