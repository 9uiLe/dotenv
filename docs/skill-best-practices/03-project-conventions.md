## AskUserQuestion による対話的情報収集

### 基本パターン

ユーザーからの情報収集は `AskUserQuestion` を使用する。以下のフィールドを必ず指定する:

- `question`: 質問内容
- `header`: セクション見出し（最大12文字）
- `multiSelect`: 複数選択の可否
- `options`: 選択肢のリスト

### 選択肢の設計ルール

| ルール | 説明 |
|--------|------|
| 太字タイトル + 説明 | 各選択肢は `**タイトル**: 説明文` の形式 |
| 4つ程度が目安 | 選択肢が多すぎると選びにくい |
| Other で自由記述可能 | 選択肢にない場合の逃げ道を確保（自動提供） |
| 段階的収集 | 1つの質問で全てを聞かず、段階的に深掘り |

### 複数質問の同時表示

関連する複数の質問を同時に表示する場合、`questions` 配列にまとめて送信する。

```markdown
AskUserQuestion で収集（**4つの質問を questions 配列にまとめて送信**）:

#### 質問 1: ゴール
- question: "この作業のゴールは何ですか？"
- header: "Goal"
- multiSelect: false

#### 質問 2: スコープ
- question: "含めないものはありますか？"
- header: "Scope"
- multiSelect: true
```

## SubAgent（Task）への複雑処理委譲

### 委譲すべきケース

| ケース | 理由 |
|--------|------|
| 大量のログが発生する処理 | メインコンテキストの汚染を防ぐ |
| 並列実行が有効な処理 | 複数 Agent を同時起動で高速化 |
| 専門的な分析・レビュー | 専用プロンプトで精度を向上 |
| 外部ドキュメントの参照 | コンテキストを分離して参照 |

### 呼び出しパターン

```markdown
### ステップ N: SubAgent への委譲

`Task(agent-name)` を呼び出し:

#### 呼び出しプロンプト例

以下の要件に基づいて分析してください:

- 対象: {対象}
- 観点: {観点}

分析結果をサマリーとして返してください。
```

### 並列呼び出し

複数の SubAgent を同時に起動する場合は、明示的に「並列」と記載する:

```markdown
### ステップ N: 並列分析

以下の SubAgent を **並列** で起動:

- `Task(agent-a)`: 観点 A の分析
- `Task(agent-b)`: 観点 B の分析
- `Task(agent-c)`: 観点 C の分析
```

## 検証ステップの組み込み

### スキルタイプ別の検証方法

| スキルの対象 | 検証ツール/Agent |
|-------------|-----------------|
| `.claude/` 配下のファイル | `Task(claude-instruction-reviewer)` |
| Shell スクリプト | `Bash(shellcheck *)` |
| ビルド成果物 | `Task(ビルド検証 Agent)`（プロジェクトに応じて定義） |
| Git 差分 | `Task(diff-review 系 Agent)`（プロジェクトに応じて定義） |

### 検証ステップのテンプレート

```markdown
### ステップ N: 品質検証

#### N.1 {検証名}

{検証コマンドまたは Agent 呼び出し}

{検証名}で問題が検出された場合:
- 自動修正可能なもの → 自動修正
- 修正にユーザー判断が必要なもの → 内容を提示して確認
```

## 参照セクションの書き方

### ルール

- スキルが参照する全ての外部ファイルを列挙
- Agent、Rule、ドキュメント、スクリプトの順で記載
- 相対パスで記載

### テンプレート

```markdown
## 参照

- `.claude/agents/{agent-name}.md`
- `.claude/rules/{rule-name}.md`
- `docs/{doc-name}/README.md`
- `scripts/cli/{script-name}.sh`
```

## 完了メッセージのパターン

スキルの実行完了時に、結果サマリーを構造化して表示する。

### テンプレート

```markdown
## {スキル名} 完了

- **ファイル**: `{作成/変更したファイル}`
- **結果**: {結果の概要}

### 次のステップ

1. {次に行うべきアクション}
2. {任意の追加アクション}
3. コミット: `/commit`
```
