# スキル ベストプラクティスガイド

## 概要

Claude Code のスキル（`.claude/skills/*/SKILL.md`）を作成・改善する際に参照するベストプラクティスガイドです。

Anthropic 公式ドキュメントの推奨事項と、このプロジェクトの既存スキル（13スキル）から抽出した規約を統合しています。

## 対象読者

- スキルを新規作成する場合
- 既存スキルを改善・リファクタリングする場合
- スキルのレビューを行う場合

## ドキュメント一覧

| ファイル | 内容 |
|----------|------|
| [01-core-principles.md](./01-core-principles.md) | コア原則（簡潔さ、自由度、段階的開示） |
| [02-skill-structure.md](./02-skill-structure.md) | スキル構造（フロントマター、セクション構成、ディレクトリ構成） |
| [03-project-conventions.md](./03-project-conventions.md) | プロジェクト固有規約（既存パターンから抽出） |
| [04-checklist.md](./04-checklist.md) | スキル作成・レビューチェックリスト |
