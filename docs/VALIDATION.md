# 模擬環境の検証結果

2026-10-20実行。**全34件のテスト、Git受信の通し確認14項目、配布・停止・復元の通し確認28項目が成功した。** 本物の設定は変更していない。

## 観測した結果

| 項目 | 結果 |
| --- | --- |
| 配布先 | 個人のCodex、仕事のCodexとClaude Codeへ、共通ルール・スキル・Hook登録・スクリプトを配置 |
| 更新時刻 | 09:59は未実行、10:00は更新、同日の再実行は抑止、翌日10:00は次の版を反映 |
| Hookの実出力 | 配布したスクリプトを子プロセスで起動し、`共有設定 v1 → 共有設定 v2 → 復元後に共有設定 v1`を確認 |
| 停止と再開 | 更新だけ・共有Hookだけを個別に停止。更新を再開してもHookの停止状態を保持 |
| 旧版への復元 | 差分プレビューで変更なし。適用後は共通部分を揃って旧版へ戻し、自動更新と共有Hookを停止 |
| 導入取り消し | 既存設定と導入後の個別追記を保持。共有ファイルは削除せず退避 |
| 再起動をまたぐ継続 | 別プロセスのCLI操作で、管理状態の保存・読み直し・復元を確認 |
| 既存Hookとの共存 | JSON設定内の既存Hookを保持。CodexのTOML内Hookも、コメントやモデル設定とともに保持 |
| Gitからの受信 | 専用キャッシュへコミットを取得し、manifestに記載されたルール・スキル・Hook・スクリプトを配布 |
| Gitの更新 | v1から翌日10:00にv2を取得。設定停止中・10時前・成功済み同日は取得処理も省く |
| 取得失敗・履歴変更 | 取得先の停止、履歴の巻き戻し・分岐、不正なmanifestやリンクを拒否し、適用済み版を保持 |
| 受信と適用の記録 | v3の取得後に配布が失敗しても、適用済みコミットと履歴検査の基準はv2を保持。手動復元でも受信基準は巻き戻さない |
| 更新プレビュー | 候補を取得して差分だけを表示し、配布先と適用済み状態を変更しない |
| 導入差分案 | 指定ホームを読み取るだけで、別の私有フォルダへ差分を生成。元の内容・時刻・権限・inodeが変わらず、通信しないことを架空ホームで確認 |
| ローカルデータの失敗 | ローカル共有元の欠損・不正でも旧版を維持し、同日の再試行が可能 |
| 競合と改変 | 配布先の共通部分、配布したスクリプトや補助ファイル、日次設定の直接編集を検出して停止 |
| 書き込み途中の障害 | 障害を注入して、配布先と有効なHookを旧版へ復旧 |
| プロセス強制終了 | 更新途中で終了後、共有Hookは停止。次回実行で旧状態へ復旧してから日次判定を行う |
| 同時操作・範囲外指定 | 排他ロック中の更新、マーカーのない場所、範囲外パス、シンボリックリンク、パスの逸脱を拒否 |

既存Hookは登録が残ることを確認している。既存Hookそのものの実行は、この試験の対象に含めていない。

## 検証の再現

全34件の内訳は、既存の配布・停止・復元・CLIが19件、Git受信が10件、Git用CLIが2件、読取専用の導入差分が3件。Gitの試験は実際のGitコマンドとローカルのリポジトリを使い、GitHubには接続していない。

導入差分は指定した1台を個人用・仕事用にした場合の2案で、もう一台の現状は反映しない。本番用ランタイムとインストーラーが未提供のため、そのまま適用できるパッチではない。起動コマンドは予定の配置先を示す。

検証で生成した `.prototype/` の模擬ホーム、結果、バックアップ、既存設定のコピーと差分は削除した。GitHubへは送信していない。別のPCや新しいチェックアウトでは、下のコマンドで検証を再現する。実装・試験・デモのソースは `prototype/` にある。

```sh
python3 -m unittest discover -s prototype -p 'test_*.py' -v
python3 prototype/demo.py
python3 prototype/git_demo.py
```

統合テストは設定ファイルと配布・復元処理、Hook起動の連携を保証し、CLIテストは別プロセスでの操作と既定のプレビューを保証する。通しデモは利用の流れと観測値を日本語で残す。

毎日10:00のplistは模擬ホーム内へ生成し、PythonとmacOSのplist検査で形式を確認した。OSへの登録・読み込みは行っていない。

## 実環境で確認する必要があること

- 実際のGitHubからの取得・認証。受信処理の試験はローカルGitを使っており、各MacのGitHub接続は別途確認する。
- OSによる毎日10:00の自動起動、ログイン後・スリープ復帰後の起動。日時を指定した判定試験のみ実施。
- CodexとClaude Codeによる実ファイルの読み込みと、Hookの信頼確認。アプリは起動していない。
- 実際に使うHookと、その実行環境。例は外部通信・ファイル変更のない単独Pythonスクリプト。
- ロックに協調しない他アプリとの同時編集、すべてのOS・ディスク障害。検査直後の外部変更を完全に防ぐ仕組みではない。

次の段階で本番適用へ進む場合も、[変更対象と停止・復元方針](SETUP_PLAN.md)をもとに各Macの実際の差分を提示し、確認を得てから設定する。
