# 導入前の確認資料

Mac向けの導入用ランタイム、差分作成、明示適用、日次登録、停止・復元を実装している。個人用Macで共有ルール・スキル・会話開始時Hookの導入を確認済み。PC共通Gitフックは模擬環境で検証し、実機反映は未実施。

変更対象・既存設定の保持・停止と復元の正本は[Macへの導入手順](MAC_INSTALL.md)。実際の差分は、対象のMacで`ai_knowledge plan`を実行して確認する。

## 確定した方針

- 原本はリポジトリで編集し、共有する内容と送信タイミングは本人が決める。
- 共通化できる知識だけを共有し、会社・案件固有の情報と認証情報は含めない。
- 各Macは現地時刻の毎日10:00に、CI成功済みの共有版を受信・反映する。
- 個人はCodex、仕事はCodexとClaude Codeを対象にする。
- 更新停止と共有Hook停止は独立させる。復元・取り外しは差分確認後に明示適用する。
- 初回適用前に、各Macの実際の差分とバックアップ先を確認する。

## 初回導入後に残る確認

模擬環境では、配布済みランタイムを別プロセスから実行し、10:00判定、停止、復元、模擬OS登録、既存設定保持を検証している。[検証範囲](VALIDATION.md)を参照。

個人用MacでLaunchAgent登録、Codexの共有設定読み込み、共有Hookの信頼確認を実施した。自然なログイン・スリープ復帰時の起動、会話中のHook呼び出し、仕事用MacとClaude Codeでの読み込みは未確認。各Macで具体的な差分を確認し、初回導入時にそのMacの動作を確かめる。
